Sentence Tray

Accepted patterns (simple on purpose)

  • DET + NOUN + VERB
  • DET + NOUN + VERB + DET + NOUN
  • PRON + VERB
  • PRON + VERB + DET + NOUN
  • PRON + VERB + PREP + DET + NOUN
  • DET + NOUN + ADJ + VERB
  • DET + NOUN + VERB + PREP + DET + NOUN

This is a “grammar-first” version — we’re not enforcing full agreement yet (but it’s easy to add later).
